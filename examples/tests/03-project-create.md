# Create a project

Goal: a signed-in user can create a new project and see it in the list.

Steps:

1. Sign in at `<target_url>/sign-in` with a test account
2. From the dashboard, start the "New project" flow
3. Enter a unique project name and submit
4. Confirm the new project appears in the project list
5. Return FAILED with the exact broken step and any visible error if it does not
